01 — Selected work

Things I've built recently

Multi-agent code generator
Code

AutoCode

An autonomous, self-verifying coding agent that runs on local or hosted models.

  • Plans, writes, critiques, patches and runs the code in a closed loop until tests pass or a retry limit is hit.
  • Ten reviewer personas (security, performance, reliability, testing…) score every change against their own plan.
  • Ships as a desktop app, a CLI, an MCP server for Claude Code / Cursor, and an A2A agent other agents can delegate to.
  • Mix Ollama, vLLM, OpenAI, Anthropic, Gemini, OpenRouter and more per pipeline step.

Offline-first retail ERP
Code

Hisaab

Billing, stock, money and GST for Indian shops: fast at the counter, honest in the books.

  • Keyboard-first billing with up to 9 open bills, UPI / split / udhaar, barcode and weighing-scale support.
  • Double-entry books in whole paise; every voucher balances, every bill saves completely or not at all.
  • Counters bill offline and sync later; printer and scale calls run with deadlines so the counter never freezes.
  • GSTR-1, GSTR-3B, e-Way Bill, e-Invoice and one-click Tally XML export.

04 — About

A bit more

I'm Swayam, an AI Systems Engineer and a BCA student at IGNOU. Most recently I spent 14 months at 1Gen, going from data science intern to AI Systems Engineer. I like the space where models meet messy reality: agents that have to prove their code works, retrieval that has to be measured instead of eyeballed, and software for shop counters where a frozen screen means a lost sale.

Most of what I build starts as "this should exist" and ends as something people can install. I write READMEs that explain the why, test with synthetic data so things run anywhere, and prefer deterministic logic wherever an LLM isn't needed.

Outside work I'm involved with the Vrikshit Foundation, using tech for social impact, and I spend downtime on competitive FPS and strategy games or a lo-fi / alt-rock playlist.
